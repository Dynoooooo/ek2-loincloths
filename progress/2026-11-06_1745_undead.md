**Problems and workarounds**
- Making a **landless** character the player shows the "You have been deposed" window at once. It can't be closed with keys, and the barbershop opens behind it.
  - `effect set_player_character = global_var:a` then fails ("Scoped character is not a player").
  - The console `play <internal id>` does switch back. Get the internal IDs with `effect global_var:a = { debug_log_scopes = yes }` and read them in `logs/debug.log` (Aldrydd was 9674 in this run).
  - Escape on the deposed window opens "Exit Game"; a second Escape cancels it.
- Console `observe` with the deposed window and the barbershop still open **crashed CK3**: GUI data update, `SPdxDataStatement::FetchData`. Never use `observe` in tests.
  - The crash dump `crashes/ck3_20261106_174237` (41 MB, with `last_save.ck3`) was left in the CK3 folder.
  - `stop` still restored everything.
- **An undead player means Game Over in EK2.**
  - EK2's `common/scripted_rules/00_rules.txt`, rule `is_character_allowed_to_be_player`, needs `NOT = { has_trait_with_flag = mindless_character }`. `undead_character` has that flag, but `lich_character` doesn't.
  - So `add_trait = undead_character` on the player opens the Game Over ("Your lineage has come to an end") at once, even while paused. The character is still alive.
  - That window sits on the `confirmation` layer, above the barbershop, and has no close key. Its only buttons are Observer, Choose new Character and Exit.
  - The barbershop keys still work under it: `h` hides the UI, `x`/`z` zoom, `a`/`d` rotate.
  - The female grave-wrap shot in the first launch probably hit the same rule.
- Shell variables and `~/.copilot/bin/ck3ctl` (tilde) are denied; use `~/.copilot/bin/ck3ctl` in full.
- `sips` and Python PIL aren't available; resize and crop screenshots with `magick` (ImageMagick).

**How to test** (one launch, after `ck3_test.sh start`, `wait`, Return)
1. As Aldrydd first:
   - `effect set_global_variable = { name = a value = root }`
   - `effect add_trait = lich_character`
   - `effect open_view_data = barbershop`
   - Screenshot → `lich_regalia_m.jpg`.
2. Create the woman in one line (`create_character … save_scope_as = c } set_global_variable = { name = c value = scope:c }`).
3. Give her a county so she isn't landless: `effect root = { random_held_title = { limit = { tier = tier_county NOT = { this = root.capital_county } } save_scope_as = t } } global_var:c = { get_title = scope:t }`.
4. Then:
   - `effect set_player_character = global_var:c`
   - barbershop → screenshot `colour_recheck3_f.jpg`
   - `add_trait = undead_character` and `set_predetermined_decay_effect = { DECAY = 1 }` (DECAY 0.5 shows the draugr skin without the skeleton shader)
   - barbershop → screenshot `undead_grave_wrap_f.jpg`.
   - Note: making the player undead triggers EK2's Game Over (see Problems), and the barbershop then opens behind it. Do the undead step last.
5. `bash source/tools/ck3_test.sh stop`.
